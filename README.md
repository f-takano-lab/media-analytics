# Media Analytics
個人運営のメディア[`deepintoanalytics.com`](https://deepintoanalytics.com/)を用いて、最上流のビジネス設計・戦略設計から下流のデータ分析までを一気通貫で実行する Web メディア定量分析プロジェクト

## プロジェクトの目的
[`media_business_design.md`](docs/business_design/media_business_design.md) で定めたビジネスゴールと戦略について、その達成状況と妥当性を定量的に評価し、データに基づく改善サイクルを回す。

[`project_guide.md`](project_guide.md) を参照
